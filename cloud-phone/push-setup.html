Reminder keys.

One-time owner setup. Keys are generated on this device using Web Crypto. This page does not upload or save them. Do not share the private key in chat, screenshots or GitHub.

Copy the values only into your Supabase Edge Functions secrets. Generating a new pair after registering phones requires re-registering those phones.

Also add ORBIT_VAPID_SUBJECT with a contact address in this format: mailto:you@example.com

Close this page when finished. It does not save the values.
